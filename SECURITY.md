# Security policy

Gatemine invokes `pi` to request gate source and executes accepted generated gates locally for
red/green verification. Generated code therefore has the authority of the local developer account.
Run generation only for corrections and model providers you trust.

Report a vulnerability through the repository's private security-advisory channel. Include the
correction string, generated artifact, command output, and a minimal reproducer. Do not publish an
exploit before maintainers have acknowledged the report.
